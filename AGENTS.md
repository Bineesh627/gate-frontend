# AGENTS.md

## Project Context

This is a standalone React + Vite application for Gate Hypermarket. Keep changes focused on the user's request and preserve existing project conventions.

## Key Files

- `src/`: frontend application source.
- `src/api/authClient.js`: frontend auth & API client.
- `vite.config.js`: Vite configuration and path aliases.
- `src/lib/gateData.js`: Data models for stores, flyer campaigns, and blog posts.

## Working Notes

- Use `npm run dev` for local development.
- Use `npm run build` to create production bundles.
- Run `npm run lint` and `npm run typecheck` before finishing code changes.
